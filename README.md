# Crypto Engine

This repository contains a single `index.html` file for the Crypto Prediction Suite dashboard.

## Vaulted Copy

The `index.html` file is the complete dashboard build. Keep a copy of it in a Google Doc or email draft for safe keeping.

## How to publish with GitHub Pages

1. Open `github.com` in your phone browser and log in.
2. Tap the `+` icon in the top right and select **New repository**.
3. Name the repository `crypto-engine`.
4. Set the repo to **Public** and tap **Create repository**.
5. On the repo page, tap **uploading an existing file**.
6. Tap **choose your files** and select the `index.html` file.
7. Scroll down and tap **Commit changes**.
8. Go to the **Settings** tab.
9. In the left sidebar, select **Pages**.
10. Under **Branch**, choose `main` and click **Save**.
11. Wait 60–90 seconds, then refresh the page.
12. You should see a banner with a live site URL.

## Notes

- This is a front-end only file. No server-side code is required.
- If the page breaks, re-upload the saved `index.html` file from your backup copy.
- Keep `dryRunMode = true` in the script until you are ready to switch it off.
