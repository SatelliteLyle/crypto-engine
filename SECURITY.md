## Reporting a Vulnerability

We take security vulnerabilities seriously. Please **do not** open a public GitHub issue for security vulnerabilities.

### How to Report

If you discover a security vulnerability in crypto-engine, please report it by emailing:
- **security@crypto-engine.dev** (primary contact)
- Or use GitHub's private vulnerability disclosure feature at: https://github.com/SatelliteLyle/crypto-engine/security/advisories

### What to Include

When reporting a vulnerability, please provide:
- Description of the vulnerability
- Steps to reproduce or proof-of-concept code
- Affected version(s)
- Any potential impact assessment
- Your name and contact information (optional but appreciated for credit)

### Response Timeline

- **Acknowledgment**: We will acknowledge receipt of your report within 48 hours
- **Initial Assessment**: Within 5 business days
- **Status Updates**: We will keep you informed every 7 days with progress updates
- **Resolution**: We aim to release security patches within 30 days of confirmation for critical issues

### What to Expect

- If accepted: A security patch will be released, and you may be credited in our security advisories
- If declined: We will explain why the issue doesn't meet our security criteria
- Coordinated disclosure: We ask for 90 days of embargo before public disclosure to allow time for patches

## Security Best Practices

When using crypto-engine:
- Always keep the library updated to the latest version
- Review the [CHANGELOG](CHANGELOG.md) for security updates
- Report any suspected vulnerabilities immediately
- Use strong, cryptographically-sound parameters
- Never commit cryptographic keys or secrets to the repository
